Point this client at your own node

This client reads Farcaster from the Snapchain read node you run, not from a hosted API. Writes are signed by an app key you delegate below.

  1. 1 · Import your seed phrase

    Used once, on this machine, to prove you control the account. It is never written to disk. Use a test account.

  2. 2 · Issue an app key

    A gasless, scoped key registered straight to your node. No Optimism transaction, no gas.

Handling seed phrases safely

A seed phrase is the root of the account, like rm -rf is the root of a filesystem. Anyone holding it can move the account's custody address and revoke every key.

  • Test with a throwaway account, never your main one.
  • Only paste it into software you can read the source of — this one.
  • Prefer delegated signers: the key below can be revoked and expires.

Client filter

Every cast is signed by the app key that posted it. Those keys carry a verified requestFid — the app that asked for them — so you can pick which clients appear in your feed.
